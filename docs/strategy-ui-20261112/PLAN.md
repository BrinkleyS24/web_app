# Strategy Alerts revision plan before code changes

Evaluation criteria: the customer can identify the observed pattern, its sample/scope and one relevant next step without reading methodology first. A current sample of zero or one distinct role is explicitly insufficient; no repeated gaps is reserved for at least two current role checks. A valid negative is scoped to the checked default document, never a qualification verdict. Failed/malformed reads never become a successful empty state. Evidence, exact source links, all returned findings and required/evidence/preferred distinctions remain accessible. Grade actual populated and failure states separately from deployment status.

Implementation: preserve backend scoring/source coverage and API routes. Validate Strategy/Resume Gap payloads at the page's query boundary; keep owner-keyed caches and withhold failed cached analyses. Lead finding cards with title, supporting statistic and next step; fold full explanation under evidence. Map known interview-review and role-fit findings to honest existing Prep/Apply Gate destinations; keep unknown actions in Next Actions. Keep commitments/debriefs connected to existing tasks/Dashboard without copying their forms. Give resume patterns explicit no-default/no-current/one-role/sufficient-no-repeat/repeated states. Put sample exclusions behind a clear evidence disclosure, while the current scope/critical limitations stay visible. Replace silent gap truncation with accessible disclosure of remaining results if needed. Render experiments as optional context with one principal action, not a competing call to action.

Dependencies: existing authenticated Premium page, two existing GET endpoints, source/version semantics from Apply Gate/Resumes, current invitation/general Prep entry, existing Dashboard debrief anchor, shared task invalidation. No migration, AI call, billing change, new source, global navigation or Dashboard redesign. Existing shared APIs/types remain compatible.

Risk review — failure / impact / mitigation / fallback:
- Zero/one current role labeled as no repeated gaps -> false reassurance -> explicit insufficient-sample states and distinct-role threshold -> check one further relevant posting, keep older exclusions in context.
- Malformed/success-false payload or invalid category/count -> false empty/misclassified requirement or render crash -> structural/runtime validation before query success -> retryable unavailable panel; other independent panel remains usable.
- Cached results after a refresh error/account switch -> stale/private findings presented as current -> owner-bound query keys and fail-closed display on errors, no placeholder-data reuse -> current-owner loading/error while independent content stays available.
- Collapsing evidence hides blocker/unknown/causality limits -> misleading recommendations -> preserve original recommendation, source scope and visible non-causality sentence; required/evidence/preferred labels remain visible -> original source passages one action away.
- Broad or guessed handoff -> wrong role/task/qualification -> use only verified existing route contracts, exact verdict references when supplied, known general Prep intent when no invitation exists -> generic explicitly labeled Next Actions; never invent task/submission identity.
- History/experiment interpreted as proof of cause or qualification -> unsupported career guidance -> keep observational labels and source-native caveats, don't change numeric claims or translate outcomes into eligibility -> per-role Apply Gate/current source review.
- Unknown/many gaps or long passages -> hidden findings/overflow -> show all returned gaps or disclose remainder with counts, escaped wrapping text, bounded source evidence -> scroll/disclosure with complete details, no silent loss.
- Deep link into collapsed evidence or malformed fragment -> missing destination/crash -> retain safe fragment decoding and expand only matching known source groups before scrolling -> page remains usable without fragment.
- Background refetch/racing source updates -> changing interpretation during interaction -> query atomic response, current-owner scope and existing focus-refetch rules -> explicit retry if unverifiable; read-only page writes no derived conclusions.
- New UI regression across tools -> inconsistent count/semantics -> retain shared visibility rules/sidebar count, reuse exact Prep/Resumes/Apply Gate contracts and test handoffs -> no Dashboard or shared business-rule rewrite.
- Privacy/injection -> exposure or execution of source content -> React text rendering, encoded exact links, local private real-account artifacts, no external graders/models with customer data -> sanitized reports and fixtures.
- Increased rendering/network -> latency -> reuse two existing bounded independent GETs, no per-row requests/AI, controlled disclosures only -> partial failure states retain independent usable panel.
- Release/rollback mismatch -> UI references unavailable route or loses data -> release Prep compatibility first; Strategy changes UI-only; frozen production build and local verification -> prior web release rollback; no stored data/schema rollback.
